# Achoo

킬링타임용 예쁜 쓰레기. 손가락 하나로 노는 귀여운 장난감 상자입니다. 글자는 제목뿐입니다.

## index.html · 장난감 상자 (메인)

동글동글한 세 친구(하양 곰, 파랑 고양이, 노랑 토끼)와 노는 장난감 상자입니다. 캐릭터는 이 프로젝트에서 새로 그린 오리지널 디자인입니다.

- 한 판은 장난감 5개와 마지막 "에취!"입니다. 8개 중에서 무작위로 뽑아서 판마다 순서와 배경색이 다릅니다.
- 판을 끝낼 때마다 스티커를 하나 받습니다. 친구 3명 × 옷 8벌 = 24종이고, 못 모은 것부터 먼저 나옵니다. 시작 화면의 책 아이콘에서 봅니다.
- 시작 화면의 문 아이콘은 방탈출 게임으로 가는 문입니다.

| 장난감 | 하는 일 |
| --- | --- |
| path | 물웅덩이를 피해 길을 그려 주면 친구가 그 길로 걸어가 간식을 먹습니다. |
| stretch | 볼을 잡아 쭉 늘였다가 놓으면 말랑하게 튕겨 돌아옵니다. (몸이 실제로 늘어나는 소프트바디) |
| tilt | 폰을 기울이면(또는 손가락으로 판을 기울이면) 친구들이 굴러서 포근한 구멍에 들어갑니다. |
| scratch | 이불 아래 잠든 친구들을 문질러서 찾습니다. |
| wind | 오르골 열쇠를 손가락으로 빙글빙글 돌려 감으면 친구들이 춤춥니다. |
| line | 점 개수를 보고 작은 친구부터 순서대로 줄을 세웁니다. |
| feed | 말풍선에 나온 간식을 입으로 끌어다 줍니다. 다른 걸 주면 울어요. |
| huddle | 탭하면 도망가지만, 꾹 누르고 있으면 모두 달려와 옹기종기 모입니다. |
| inflate | (마지막) 볼을 부풀리다가 동그라미 안에서 놓으면 "에취!" 하고 폭죽이 터집니다. |

## escape.html · 방탈출 (그대로 보존)

말이 없는 퍼즐 게임입니다. 폐병원 4개 층, 퍼즐 11개, 앞 층의 단서가 다음 층의 답이 됩니다.
퍼즐을 푸는 동안 단서를 카드로 띄워 둘 수 있습니다.

## 구조

- `index.html` + `toy.js`: 장난감 상자
- `escape.html` + `escape-engine.js` + `escape-rooms.js`: 방탈출

장난감 하나만 보려면 주소 뒤에 `#room=feed` 처럼 붙입니다.
