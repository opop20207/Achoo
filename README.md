# Achoo

킬링타임용 예쁜 쓰레기. 손가락으로 노는 모바일 웹앱입니다.

코 속에 들어온 먼지가 되어 한 판에 11개의 방을 내려갑니다. 처음엔 귀엽고, 갈수록 기괴해집니다.

- **방 16개 + 피날레**: 귀여움 5, 이상함 4, 섬뜩함 3, 기괴함 3. 판마다 3+3+2+2개를 무작위로 뽑아 순서와 색을 바꿉니다.
- **뒤집힘**: 방을 깨면 방금 한 행동이 사실은 무엇이었는지 드러납니다. 거품은 숨이었고, 먹은 점은 눈이었습니다.
- **숨은 눈**: 방마다 어딘가에 작은 눈이 숨어 있고, 찾으면 단서가 쌓입니다. 홈 화면의 눈 아이콘이 기록입니다.
- **엔딩 4종**: 한 행동의 숫자로 정산하고, 찾은 눈의 수에 따라 달라집니다.

## 구조

- `index.html`: 껍데기와 스타일
- `engine.js`: 입력, 소리, 한 판의 구조, 점점 깊어지는 연출(주변의 눈, 화면 찢김, 심장 소리)
- `rooms.js`: 모든 방
- `story.json`: 모든 문장. 코드를 건드리지 않고 고칠 수 있습니다.
- `worker/`: 선택 사항. 문장을 AI가 새로 쓰게 하는 Cloudflare Worker

방 하나만 바로 보려면 주소 뒤에 `#room=pluck&d=0.8` 처럼 붙입니다. `d`는 깊이(0~1)입니다.
