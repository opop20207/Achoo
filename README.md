# Achoo

킬링타임용 예쁜 쓰레기. 손가락 하나로 노는 귀여운 장난감 상자입니다. 글자는 제목뿐입니다.

## index.html · 장난감 상자 (메인)

- 한 판은 장난감 6개와 마지막 풍선입니다. 11개 중에서 6개를 무작위로 뽑아서 판마다 순서와 색이 다릅니다.
- 판을 끝낼 때마다 스티커를 하나 받습니다. 24종이고, 못 모은 것부터 먼저 나옵니다. 모은 스티커는 시작 화면의 책 아이콘에서 봅니다.
- 시작 화면의 문 아이콘은 방탈출 게임으로 가는 문입니다.

| 장난감 | 하는 일 |
| --- | --- |
| pop | 거품을 터뜨립니다. 손가락으로 쓸어도 터집니다. |
| hold | 누르고 있으면 반짝이들이 모입니다. |
| eat | 무지개 벌레가 별을 먹습니다. |
| fling | 하트와 별을 던져 해님에 맞힙니다. |
| poke | 말랑한 친구를 콕콕 찌릅니다. |
| paint | 손가락으로 화면을 무지개색으로 칠합니다. |
| stack | 미끄러지는 블록을 타이밍 맞춰 쌓습니다. |
| pet | 복슬복슬한 친구를 쓰다듬습니다. |
| catch | 바구니를 밀어 떨어지는 별을 받습니다. |
| grow | 흙을 눌러 꽃을 피웁니다. |
| inflate | (마지막) 풍선을 불다가 동그라미 안에서 놓습니다. |

## escape.html · 방탈출 (그대로 보존)

말이 없는 퍼즐 게임입니다. 폐병원 4개 층, 퍼즐 11개, 앞 층의 단서가 다음 층의 답이 됩니다.
퍼즐을 푸는 동안 단서를 카드로 띄워 둘 수 있습니다.

## 구조

- `index.html` + `toy.js`: 장난감 상자
- `escape.html` + `escape-engine.js` + `escape-rooms.js`: 방탈출

장난감 하나만 보려면 주소 뒤에 `#room=pet` 처럼 붙입니다.
