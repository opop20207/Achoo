# Achoo

킬링타임용 예쁜 쓰레기. 손가락으로 노는 다섯 칸짜리 모바일 웹앱입니다.

방마다 목표가 하나 있고, 달성하면 재채기처럼 색이 퍼지며 다음 방으로 넘어갑니다.

1. Pop: 거품 10개 터뜨리기
2. Hold: 누르고 있어서 점을 한곳에 모으기
3. Eat: 슬라임으로 점 8개 먹기
4. Fling: 글자를 던져 움직이는 과녁 5번 맞히기
5. Sneeze: 누르고 있다가 빨간 띠 안에서 놓기

`index.html` 하나로 돌아가고, `manifest.webmanifest`와 `sw.js` 덕분에 홈 화면에 추가해서 앱처럼 쓸 수 있습니다.

## 이야기

- 방을 깰 때마다 한 줄짜리 문장이 한 글자씩 나타납니다.
- 방마다 어딘가에 작은 눈이 숨어 있습니다. 설명은 없습니다. 다섯 개를 모두 찾은 채로 5번 방을 깨면 숨겨진 여섯 번째 장면이 열립니다.
- 못 찾았으면 "뭔가 빠뜨린 것 같다."와 함께 처음으로 돌아갑니다.

## 이야기 고치기

문장은 전부 `story.json`에 있습니다. 코드는 건드리지 않아도 됩니다.

- `intro`: 시작 문장 (회차별)
- `rounds[].after`: 방을 깰 때 나오는 문장 다섯 개 (마지막은 눈을 놓쳤을 때)
- `whispers`: 숨은 눈을 찾으면 나오는 단어
- `endings`: 비밀 엔딩 대사 (회차별)
- `endpoint`: 비워 두면 위 문장만 씁니다. `worker/`를 배포하고 주소를 넣으면 문장을 AI가 새로 씁니다. 응답이 늦거나 실패하면 자동으로 `story.json` 문장으로 돌아갑니다.
