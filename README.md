# Achoo

말이 없는 방탈출 모바일 웹앱입니다. 먼지 때문에 난 재채기에 눈을 뜬 폐병원에서 위로 올라갑니다.

글자는 제목뿐입니다. 이야기는 그림으로, 규칙은 만져서 알아냅니다.

## 4개 층, 11개 퍼즐 (한 번씩만 씁니다)

| 층 | 퍼즐 |
| --- | --- |
| 1 로비 | lantern(어둠 속 화살표) · gaze(초상화 눈 돌리기) · tear(찢긴 사진 맞추기) |
| 2 복도 | clock(멈춘 시계) · wires(전선 잇기) · pulse(심장 소리 세기) |
| 3 지하 | simon(색 버튼) · wipe(먼지 낀 거울 닦기) · dial(금고 주사위) |
| 4 옥상 | align(점 두 겹 맞추기) · sneeze(마지막 문) |

## 층이 이어지는 방법

- 1층 사진의 시계가 멈춘 시각 → 2층 clock 퍼즐의 답
- 1층 lantern의 화살표 → 같은 층 gaze의 답
- 2층 전선 색의 순서 → 3층 simon의 답 (버튼은 제멋대로 깜빡이지만 순서는 전선에 있습니다)
- 3층 거울의 주사위 → 같은 층 금고의 답
- 3층 금고의 열쇠 → 옥상 문
- 풀어야 할 순서가 있는 물건은 잠겨 있고, 앞의 것을 풀면 열립니다.
- 얻은 단서는 화면 아래 줄에 그림으로 쌓입니다. 단서를 누르면 화면 아래에 카드로 고정되어, 퍼즐을 풀면서 계속 볼 수 있습니다(카드 위로도 조작이 통과합니다). 다시 누르면 내려갑니다. 단서가 필요한 퍼즐에 들어가면 카드가 자동으로 떠 있습니다.

## 숨은 사진 4장

1층 사진은 퍼즐을 풀면 얻고, 나머지 세 장은 2~4층 어딘가에 작은 흰 사각형으로 숨어 있습니다. 모은 사진은 시작 화면의 눈 아이콘에서 봅니다. 네 장을 모두 모으면 엔딩이 달라집니다.

판마다 정답(화살표, 전선 색, 주사위, 박동 수)이 새로 정해집니다. 한 층을 탈출하면 시작 화면에서 그 층부터 다시 시작할 수 있습니다.

## 구조

- `index.html`: 껍데기와 스타일
- `engine.js`: 입력, 소리, 판의 흐름, 소지품, 이야기 그림 4장
- `rooms.js`: 층 장면과 퍼즐

퍼즐 하나만 보려면 주소 뒤에 `#room=clock` 처럼 붙입니다.
