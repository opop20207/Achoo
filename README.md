# Achoo

킬링타임용 예쁜 쓰레기. 손가락 하나로 노는 귀여운 장난감 상자입니다. 글자는 제목뿐입니다.

## index.html · 장난감 (메인)

규칙도 실패도 없습니다. 누르면 바로 소리, 진동, 움직임이 돌아옵니다.

- **왁스볼**: 톡톡 두드릴 때마다 금이 가고 "빠자작" 소리가 납니다. 깨지면 안에서 친구가 튀어나옵니다. 탭하면 다음 공이 나옵니다.
- **뽁뽁이**: 누르거나 쓸어서 터뜨립니다. 가끔 모은 친구가 숨어 있습니다.
- **말랑**: 몸을 쭉 늘였다 놓으면 말랑하게 튕겨 돌아옵니다. (소프트바디)
- **도감**: 친구 14종 × 색깔 3종 = 42종. 보통(★), 레어(★★), 반짝(★★★)이 있고 반짝은 공이 무지개빛으로 변합니다. 겹치면 개수가 늘어납니다.

친구들은 이 프로젝트에서 새로 그린 오리지널 디자인입니다. 전부 코드로 그립니다(`art.js`).

## escape.html · 방탈출 (그대로 보존)

말이 없는 퍼즐 게임입니다. 폐병원 4개 층, 퍼즐 11개, 앞 층의 단서가 다음 층의 답이 됩니다.
퍼즐을 푸는 동안 단서를 카드로 띄워 둘 수 있습니다.

## 구조

- `index.html` + `art.js`(친구와 소리) + `toy.js`(화면): 장난감
- `escape.html` + `escape-engine.js` + `escape-rooms.js`: 방탈출

장난감 하나만 보려면 주소 뒤에 `#room=squish` 처럼 붙입니다.
